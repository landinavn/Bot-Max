# Bot-Max

Бот MAX для создания одного плаката по фото и сфере жизни.

Установка и запуск:

```bash
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`, заполните токен MAX, ключ OpenAI и
настройки публичного бакета Yandex Object Storage. Затем запустите:

```bash
python bot.py
```

При первом `/start` начисляется один бесплатный кредит. Один кредит покрывает
одну успешную генерацию одного изображения; кнопка «Ещё» запускает новую генерацию.
Ошибки генерации не списывают кредит. После сбоя отправки уже созданный плакат
можно отправить повторно без дополнительного списания, повторив ту же сферу жизни.
После списания последнего кредита бот предлагает пакеты с кнопками покупки.
При попытке генерации с нулевым балансом предложение автоматически не повторяется.
`/buy` показывает пакеты: 5 кредитов за 299 ₽ и 15 за 699 ₽; оплата пока недоступна.
`PRODAMUS_DOMAIN` и `PRODAMUS_SECRET_KEY` зарезервированы для будущей интеграции.

Баланс и факт использования пробного кредита хранятся в `database.sqlite3`
рядом с кодом. Файл создаётся автоматически и исключён из Git. Сохраняйте его
при обновлениях и перезапусках; в контейнере разместите его на постоянном томе.
Удаление или замена базы удаляет историю пробных кредитов.
Запускайте один экземпляр бота с этой базой: генерации одного пользователя
в разных чатах сериализуются внутри процесса, а операции SQLite атомарны.

Проверка:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```
