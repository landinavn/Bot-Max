# Точные промпты минутной мульт-открытки ко Дню матери

Шесть сцен по 10 секунд. Ниже содержимое `prompt`, передаваемое в HeyGen для каждого клипа. Индивидуальный первый кадр создаётся по `BASE + FIRST FRAME ONLY + starting state`; первый/предыдущий кадры прилагаются как референсы, лицо — из утверждённого аватара. Мама молчит и может улыбаться с сомкнутыми губами. Песня добавляется отдельно.

Эти тексты формируются функциями `image_prompt` / `video_prompt` из `mother_storyboard.py`.
