## Сцена 3

Говорит только взрослая Аня, используется её сохранённый голос и скорость
1.05. Весь текст реплики сохраняется; старая озвучка Маши к нему больше не
подставляется. Требуется новая озвучка и её обычная проверка до 4.5 секунд.

Кадр — средний план по пояс, Аня в кремовом свитере за прежним столом.
Видны торс, обе руки, телефон и край стола; предметы остаются в центральной
части изображения с запасом по краям для вертикального монтажа. Рот закрыт,
зубов не видно. Маша и другие люди **за кадром**. Парная композиция из примера
владельца остаётся в архивной вставке 2а; она не используется в текущей сборке.

Промпт учитывает структурное поле `framing=medium`: вместо прежнего общего
разрешения крупного плана явно требует средний план. Для 6а `framing=wide`
требует общий план, а не лицо крупным планом.

## Немая анимация тоже через HeyGen

Новые немые сцены/новые запросы для пятисекундных немых сцен используют
**HeyGen Video `heygen-video-1`, `image_to_video`**, а не Talking Photo/аватар
и не Kling. Контракт: [официальная документация](https://developers.heygen.com/docs/models/heygen-video.md).

- Один POST `/v3/models/videos`: картинка, описание движения, `duration=5`,
  `resolution=1080p`, `prompt_enhancement=disabled`.
- Затем только GET `/v3/models/videos/{video_id}`. Неизвестный исход POST
  автоматически не повторяется. Чужой/ошибочный ответ не подменяется другим
  платным способом генерации.
- Нет создания аватара, озвучки, TTS, синхронизации губ или голосовых ID.
- Промпт требует отсутствия речи и музыки. У API нет выдуманного параметра
  отключения звука: возвращённая моделью дорожка удаляется при локальной
  нормализации, в результат записывается тишина. Общая музыка добавляется
  только при сборке серии. Итоговый блок — 150 кадров / 5 секунд / 30 FPS.
- Режим image_to_video следует пропорциям первого кадра; окончательный формат
  1080×1920 формируется существующим монтажом. Новый промпт оставляет боковые
  поля, чтобы сохранить руки и телефон.

Готовые немые ролики и уже подтверждённые старые запросы сохраняют прежнего
провайдера из снимка задания. Новый запрос выбирает HeyGen Video, не меняя
спецификацию готовой сцены и не скрывая её старые результаты.

## Сохранение готовых файлов и порядок монтажа

Исходные номера и ID сцен 1–9 не меняются. Вставки получают отдельные ID и
внутренние номера 10/11. Теперь 10 (**2а**) исключена; в меню остаётся **6а**. Порядок
хранится в `cartoon_episodes.spec.scene_order`, отдельно от визуального хеша
каждой сцены. Поэтому перестановка блоков не отрывает готовые изображения,
MP3 и видео от остальных сцен. Финальная заставка остаётся в последнем блоке
исходной сцены 9; вставка 6а не оказывается после титров.

Однократная миграция изменяет только исходную сцену 3, спецификацию третьей
серии и добавляет две вставки. Неотправленные задания старой сцены 3 отменяются,
чтобы не тратить запрос на прежнюю Машу. Оплаченные/уже отправленные задания,
все ассеты и история версий остаются в базе; старые файлы не переписываются.
Старые готовые сборки 45 секунд доступны через архив заданий, новая сборка
требует обновлённый набор сцен; 50 секунд — исходный таймлайн до обрезки хвостов.

Дополнительная однократная миграция `episode_three_trim` исключает 2а через
`cartoon_episodes.spec.excluded_scene_ids` и удаляет её ID из `scene_order`.
Ни одна спецификация сцены, её ID, визуальный хеш или файл не меняются.
Неотправленные задания 2а и старой сборки отменяются; отправленные платные
запросы и готовые результаты сохраняются. Сборки 45/55 секунд также остаются
в архиве. Для текущего варианта нужно заново нажать «Собрать серию»; остальные
готовые клипы перегенерировать не требуется.

Повторные старты не дублируют вставки и не стирают ручные правки. Если состав
серии до миграции отличается от исходных девяти сцен, обновление этой серии
останавливается с понятной ошибкой, а не перезаписывает пользовательский монтаж.
Другие проекты и серии 1/2 не меняются.

## Ограничение HeyGen на говорящие аватары

[HeyGen запрещает аватары, изображающие людей младше 18 лет](https://www.heygen.com/moderation-policy),
включая мультперсонажей, что также подтверждено поддержкой владельцу.
Новые запросы говорящих аватаров с явно указанным детским возрастом персонажа
блокируются до отправки. Маша остаётся ребёнком; возраст и внешность не
подменяются. Взрослая Аня произносит реплику, немой семейный кадр не использует
аватарный режим. Наличие ранее созданного аватара Маши не разрешает новые
запросы с ним: запрет относится к персонажу, а не только к загрузке новой
картинки. Старый avatar_id не используется для повторной отправки отклонённого
персонажа. Уже сохранённые результаты не перегенерируются.
Проверка возраста по описанию — дополнительная защита от ошибочного запуска,
а не автоматический анализ всех лиц картинки: кадры просматривает администратор.

## Короткие хвосты HeyGen и русская заставка с QR

Последняя правка применяется только к третьей серии при новой сборке:

- У подтверждённых HeyGen / HeyGen Video клипов удаляется **до двух секунд с конца**. Провайдер определяется по сохранённому заданию выбранного видео, а не по текущей настройке сцены. Kling, картинки и клипы неизвестного происхождения не обрезаются.
- Реплика сохраняется полностью: если последние две секунды захватывают MP3, кадр заканчивается не раньше конца утверждённой озвучки. Округление идёт вверх до целого видеокадра. Голос не ускоряется, начало не сдвигается; исходный MP3 и исходное пятисекундное видео не меняются.
- Обрезанный блок не дополняется обратно до пяти секунд. Субтитры и музыка собираются по фактическим длительностям новых блоков; окончательная длина проверяется по их сумме. Пятисекундные исходники и их проверки остаются прежними.
- Последний блок заменяется отдельной **пятисекундной русской заставкой**: «Маленькие чудеса Ани», «Продолжение следует…», приглашение создать карту желаний и QR-код. В качестве фона используется утверждённая картинка квартиры последней сцены, без чёрного/английского окончания видео провайдера. Если подходящей картинки нет, используется тёплый однотонный фон.
- QR создаётся локально, ведёт на настроенный `BOT_LINK`, имеет целочисленные модули и белое поле вокруг. Ссылка сохраняется в спецификации серии и снимке задания, чтобы подтверждённый монтаж был воспроизводимым. Одна заставка остаётся на экране пять секунд; её не укорачивают.
- Новая одноразовая миграция изменяет только монтажные поля серии, отменяет ещё не начатые устаревшие сборки и не трогает сцены, их хеши, одобренные файлы, отправленные запросы и архив. Версия нового профиля сборки — 5; старые серии сохраняют профиль 4.

Обновить зависимости перед перезапуском: `venv/bin/pip install -r requirements.txt`.
Для генерации QR добавлен `qrcode`; `zxing-cpp` нужен только для тестов сканирования
и находится в `requirements-dev.txt`. Платных генераций и новых API-ключей нет.
Для применения к уже готовым сценам достаточно снова нажать «Собрать серию».

## Обновление

Сначала резервная копия базы и `studio_files/`. После слияния PR:

```bash
cd ~/Bot-Max
git pull --ff-only
venv/bin/pip install -r requirements.txt
systemctl restart botmax
```

При `STUDIO_ENABLED=1` миграция выполняется при запуске. После обновления:
если новая сцена 3 с Аней и вставка 6а уже готовы, просто нажать «Собрать серию».
Иначе подготовить только недостающие результаты: сцена 3 → кадр → озвучка Ани →
видео; вставка 6а → кадр → немое видео. Вставка 2а больше не нужна. Все платные
этапы требуют отдельного подтверждения. Новые API-ключи, бюджет и сверка цен
не нужны. Дед Мороз, тарифы, оплата и пользовательские разделы не меняются.
