# Серия 3 «Мама, смотри! Ты уже на море!»

Утверждённый сценарий: [исходное задание](multstudio-episode-3-script.md).

После обновления включённой мультстудии (`STUDIO_ENABLED=1`) создаются девять
сцен третьей серии существующего проекта `anya-s1-v1`: семь говорящих и две
немые. Общая целевая длина — 45 секунд. Подготавливаются 26 черновиков:
9 изображений, 7 озвучек, 9 видео и сборка. Черновики не запускаются очередью,
не резервируют бюджет и не являются подтверждением платных запросов.
Повторный запуск не дублирует сцен и не затирает правки. При занятом номере
серии подготовка останавливается, не заменяя существующую серию.

## Персонажи и референс предыдущей серии

Используются сохранённые Аня, Дима и Маша, их утверждённые изображения и текущие
профили Yandex SpeechKit (включая детский голос Маши v3). Скорости для этой
серии: Аня 1.05, Дима 0.95, Маша 1.10. ID голосов и тембр не меняются.

Первая сцена третьей серии использует утверждённое изображение **последней
сцены второй серии** как дополнительный референс квартиры. Остальные домашние
сцены используют тот же якорь, в том числе после пляжа. Если актуального
утверждённого изображения нет, запрос изображений блокируется. Для пляжа
сцены 5 передаётся только эталон Ани, без фона квартиры. Финальная сцена без
людей использует квартиру; надписи добавляет FFmpeg, не генератор изображений.
Все референсы передаются в существующий `/images/edits`.

## Глобальные правила новых сцен

Новые сцены, создаваемые через репозиторий/меню, автоматически получают
`production_rules=single-speaker-5s-v1`, `scene_duration_seconds=5`,
`max_speakers_per_scene=1`, `speaker_id`. Немая сцена имеет `speaker_id=null`.
Диалог из нескольких реплик при добавлении разделяется на последовательные
отдельные сцены; каждый говорящий остаётся единственным персонажем своего
кадра. После разделения длительность равна новому числу сцен × 5 секунд.
Эта операция сохраняет сценарий; каждую платную генерацию всё равно надо
оценить и отдельно подтвердить. У уже существующей сцены удалить правило
или присвоить другую длительность нельзя.

Старые сцены/снимки не помечаются новым правилом и сохраняют прежний монтаж,
включая продление под речь. Персонажи, голоса, версии, расходы и файлы старых
серий не удаляются. Исторические шаблоны первых двух серий не переписываются.

## Порядок производства

1. `/multstudio` → проект → Сцены → Серия 3 → «План серии».
2. Проверить утверждённый последний кадр второй серии и эталоны персонажей.
3. Подтвердить оценку изображения каждой сцены; просмотреть и утвердить кадр.
4. Подтвердить оценку озвучки. Полученный MP3 сохраняется и измеряется.
5. Максимум речи **4.5 с**, вместе с настроенной паузой — максимум **5 с**.
   Неподходящая озвучка сохраняется как `speech_rejected`, задание требует
   ручного решения; следующий платный запрос автоматически не выполняется.
   Бот предлагает сокращение. В карточке «Изменить реплику» можно ввести новый
   текст обычными словами и затем заново подтвердить стоимость TTS.
   Утверждённая картинка при изменении только реплики переиспользуется бесплатно;
   старые речь и видео не подставляются под новый текст.
   Подсказка не заменяет реплику без согласия и не гарантирует длину: после
   новой озвучки проводится повторное измерение. Если смысл нельзя сохранить,
   добавьте две отдельные сцены с частями реплики и подтвердите новый план;
   нельзя просто увеличить `duration` или ускорить голос.
6. Только после проверки MP3 можно оценить и подтвердить говорящую сцену
   HeyGen: один Photo Avatar из её кадра, затем одно вертикальное Avatar IV
   видео с точным сохранённым аудиофайлом. Немая сцена использует Kling 5 с,
   без речи. ID каждого платного шага сохраняется; неизвестный результат POST
   не повторяется автоматически. Опрос GET имеет ограниченные повторы.
7. Оригинальное видео сохраняется. Для HeyGen проверяются наличие звуковой
   дорожки, начало звука относительно утверждённого MP3 и конец речи.
   Укорачивается только подтверждённый тихий хвост; короткий ролик дополняется
   стоп-кадром. Голос не ускоряется/замедляется, слова не обрезаются. Если
   безопасное приведение к 5 с невозможно, результат не принимается.
8. Просмотреть и утвердить каждое видео. Проверка губ/лиц остаётся визуальной
   проверкой администратора: длина сама по себе её не гарантирует.
9. Загрузить фоновую музыку в карточке серии и подтвердить бесплатную сборку.
   FFmpeg объединяет блоки по 150 кадров, MP4/H.264/AAC, 1080×1920, 30 FPS,
   экспортирует русские `.srt`, накладывает белые субтитры с чёрной обводкой,
   приглушает фоновую музыку при речи. Заставка находится внутри девятого блока.
   Переходы не добавляют секунд: используется прямой монтаж между блоками.
   Контроль итоговой длительности — число сцен × 5 с с допуском одного кадра.

`cartoon_scene_validation` хранит для актуального контекста `speaker_id`,
`voice_id`, `voice_speed`, `audio_duration_seconds`, `scene_validation_status`
и причину отказа. Озвучка фиксирует текст и профиль голоса; видео — ID исходного
кадра и MP3. Изменившийся голос или выбранный новый MP3 требуют нового видео,
а архивный файл не может случайно подменить результат текущей реплики.

## Ключи, модели и стоимость

Используются существующие `IMAGE_API_KEY`, `YANDEX_TTS_API_KEY`,
`HEYGEN_API_KEY`, `STUDIO_KLING_API_KEY`/`PIAPI_KEY` и настройки Object Storage.
Новая настройка — **`STUDIO_HEYGEN_SCENE_USD`**, общая оценка USD за создание
Photo Avatar и одного видео говорящей сцены. По умолчанию 0; настройка необязательна и не блокирует генерацию.
Бюджет и сверка стоимости больше не используются.
Реальные расценки не выдумываются. Изображения и Yandex TTS используют прежние
оценки `STUDIO_IMAGE_USD`, `STUDIO_TTS_1000_CHARS_USD`,
`STUDIO_TTS_V3_250_CHARS_USD`; немые видео — `STUDIO_KLING_5S_USD`.

Экран плана показывает модели, разрешения и количество говорящих/немых сцен.
Оценки STUDIO_*_USD необязательны. Каждый платный запуск требует подтверждения,
но нулевой бюджет, отсутствующая оценка или несверенная стоимость его не
блокируют. Исторические затраты остаются в базе, неизвестная фактическая цена
не заменяется нулём. Пакеты, платежи и пользовательские разделы не меняются.

В этой реализации реальных платных вызовов не было. Официальная документация
HeyGen оказалась недоступна из среды (сетевой HTTP 403); использован уже
работающий в проекте контракт `/v3/avatars`, `/v3/avatars/looks/{id}` и
`/v3/videos` с `audio_url`. Параметр «duration=5» в HeyGen не выдумывается:
точность длины обеспечивает локальная проверка/нормализация. При несовместимом
ответе провайдера задача останавливается. Нужен один согласованный пробный
говорящий кадр перед подтверждением расходов на остальные сцены.

Перед обновлением сделайте резервную копию SQLite и `studio_files/`.
После слияния PR: `git pull --ff-only`, перезапуск `botmax`. Подготовка
выполняется локально, без API. Фактические голоса, изображения и длительность
этой серии подтвердятся только после отдельно разрешённых платных этапов.
