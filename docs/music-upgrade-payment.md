# Апгрейд готовой открытки за 149 ₽

Порядок для клиента: готовая картинка → выбор песни и голоса → проверка/правки слов → счёт на 149 ₽ → подтверждение оплаты Prodamus → создание песни → сборка музыкальной открытки → готовое видео в бот.

До оплаты музыкальный API и видеосборка не вызываются. Слова, выбранный голос и ссылка на готовую картинку сохраняются в `musical_orders.draft` при создании счёта. Картинка используется повторно. После оплаты постоянная очередь сама создаёт песню, даже если клиент закрыл чат или бот перезапустился. Кнопка «Продолжить после оплаты» показывает состояние заказа, не запускает повторную генерацию.

Очередь сохраняет маркер отправки запроса, номер музыкального задания, ссылку на аудио и готовое видео. После сбоя опрашивается тот же номер задания; уже полученная песня/собранное видео используются повторно. Если запрос мог быть принят, но номер задания неизвестен, автоматический повтор отключается: заказ остаётся оплаченным, записывается `song_submission_unknown`, клиенту предлагается поддержка. Перед ручным восстановлением такого заказа нужно проверить запрос у провайдера.

Старые заказы с уже созданной песней продолжают сборку из сохранённых материалов. Прямая покупка музыкальной открытки за 299 ₽ и бесплатный сценарий администратора сохраняют прежнее поведение. Новых переменных окружения и миграций схемы не требуется.

Проверки без платных запросов:

```bash
venv/bin/python -m pytest tests/test_upsell_prepaid.py tests/test_musical_orders.py tests/test_song_review.py tests/test_handlers.py -q
```
