Кнопка «Примеры» показывает реальный кейс с промптом:
«Машина тесла с бордовым салоном, я за рулем».

В этой папке находятся фотографии кейса в формате JPEG:

- `before.jpg` — исходное фото, подпись «Фото до:».
- `after.jpg` — результат, подпись «Результат:».

Оба файла должны поставляться вместе с проектом. Пути вычисляются относительно
`handlers.py`, поэтому рабочая директория запуска не влияет на поиск фотографий.
Бот загружает файлы в MAX через `maxapi` и отправляет полученные вложения с токенами.
Если файл отсутствует, пользователю приходит сообщение о временной недоступности
примера. Генерация и хранилище Yandex Cloud для этого раздела не используются.

## Альбомы раздела «Фотосессия»

Добавьте следующие файлы в эту папку с точными именами:

- `photo_main_1.webp`, `photo_main_3.webp`, `Мама+дочка3.png` — альбом перед
  приветствием и кнопками стилей на экране `cat_photo`.
- `photo_fam_3.webp`, `Леденец.webp`, `кролик1.webp`, `мама+дочка.webp` — альбом
  перед тарифами при выборе «Новогодняя» (`photo_style_ny`).
- `photo_fam_3.webp`, `Мама+дочка3.png`, `кролик.png` — альбом между текстом
  и кнопками сюжетов тарифа 590 ₽ после `photo_tariff_590` и `photo_choose_template`.

Общий альбом фотосессий показывает первый и третий прежние примеры, затем
коллаж «Мама + дочка». Перед выбором новогоднего тарифа показываются первый
из прежних примеров этого экрана и три отдельных фото: «леденец», «кролик1»,
«мама+дочка», одним альбомом. Примеры сюжетов тарифа 590 ₽ сохранены.
При выборе `photo_temp_mom_daughter` отдельно показывается `Мама+дочка3.png`,
при выборе `photo_temp_rabbit` — `кролик.png`, перед оплатой или запросом фото.
На экране новогоднего тарифа 990 ₽ перед выбором сюжета показывается альбом
из `Мама+дочка5.png` и `Женщина в красном.png`. При выборе
`photo_temp_mom_daughter_5` отдельно показывается `Мама+дочка5.png`, а при выборе
`photo_temp_woman_red` — `Женщина в красном.png`. Последний коллаж содержит
пять кадров: основной портрет на белом кубе и четыре небольших фото справа.
Все коллажи — исходные PNG из чата, добавленные без перекодирования и правки;
`Женщина в красном.png` поставляется вместе с этим изменением.
После выбора тарифа показываются только альбом и кнопки сюжетов. После выбора
конкретного сюжета отправляется его собственный пример: `photo_fam_1.webp` для
семьи из трёх, `photo_fam_2.webp` для семьи 3+, `photo_fam_3.webp` для семьи с
малышами либо соответствующий именной коллаж для остальных сюжетов. Только
после успешной отправки этого примера создаётся и показывается персональная
платёжная ссылка. Если пример не загрузился или не отправился, новый счёт не
выставляется. Правило действует и для повторной покупки со скидкой.
Изображения поставляются отдельно: код не подставляет другие примеры вместо этих
файлов. При недоступном файле, ошибке загрузки или отправки ошибка записывается
в лог; доступные примеры и меню продолжают показываться.

## Примеры «Мульт-открытки»

Экран `cat_cartoon` загружает локальные файлы `cartoon_example.mp4` и
`cartoon_example1.mp4` с сервера через `maxapi` как вложения типа `video`.
Видео отправляются по очереди перед текстом и восемью темами.
Папка вычисляется относительно `handlers.py` независимо от рабочей директории.
Файлы должны находиться в этой папке на сервере; публичные URL не требуются.
Недоступные файлы и ошибки MAX логируются; следующий пример и меню продолжают
отправляться. Для `cat_cartoon_long` эти видео не отправляются.

## Главное меню

Перед приветствием отправляется альбом из семи изображений: `i (1).webp`,
`i (29).webp`, `i (28).webp`, `i (27).webp`, `Леденец.webp`, `кролик1.webp`,
`мама+дочка.webp`. Три отдельных фото заменяют прежний пятый коллаж.
Тот же набор используется кнопкой «Примеры».

Файлы `Леденец.webp`, `кролик1.webp`, `мама+дочка.webp` пользователь
размещает в `examples/` на сервере. Имена чувствительны к регистру: «мама»
пишется со строчной буквы. Код не изменяет и не перекодирует изображения.
