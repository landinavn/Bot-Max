Node 24, npm 11, зависимости уже определены lockfile; новые runtime библиотеки не добавлялись.

```bash

# В другом терминале:
```

`build` включает проверку медиа, TypeScript, Vite, SSG и проверку dist. Браузер: Chromium `/usr/bin/chromium`, либо `CHROMIUM_PATH`. Тесты блокируют внешние запросы, ничего не отправляют в MAX, платёжные или AI API.

Прежние 11 тестов сохранены и расширены до 14. Браузер проверяет 19 маршрутов, 9 viewport × 10 страниц, 7 проигрывателей, фильтры и focus/dialog, touch/keyboard сравнение, отсутствие page overflow, видимость hero/CTA, отсутствие ранних MP4/MP3 запросов, контент без JS, HTTP 404 и приватные пути. Начальная сеть измеряется в свежем контексте до scroll/click. Скриншоты блоков временно скрывают sticky header/bottom nav, чтобы не закрывать содержимое; первые экраны сняты без такого изменения.

## Реальные медиа и права

Владелец явно разрешил все 16 новых исходников, включая узнаваемых взрослых и детей, 26 ноября 2026. SHA-256 совпадают с общим `sources.tsv`; подробности и воспроизведение оптимизации: [media/README.md](media/README.md).

MP4/MP3 не имеют `src` до нажатия на видимую кнопку. Нажатие монтирует проигрыватель и вызывает play; autoplay-атрибута и фонового запуска нет. При запрете play браузером остаются native controls. Постеры оживления обозначены как кадры видео; отдельные оригиналы не предоставлены. Только прежняя пара карты желаний используется в настоящем интерактивном before/after.

Новые 48 производных файлов суммарно 8 929 620 Б. Оба MP4 вместе уменьшены с 8 540 100 до 1 458 786 Б без смены разрешения/пропорций. Размеры полного dist, initial network, проверки и снимки: [REVIEW.md](REVIEW.md).

## Контроль публикации и архив

`check:media` проверяет allowlist, уникальность записей, размеры и SHA каждого файла. `check:dist` разрешает только 20 HTML, robots/sitemap, хешированные клиентские JS/CSS и зарегистрированные медиа: всего 89 файлов. README, TSV, служебные JSON, permissions, `.env`, Git, Python, БД, node_modules, sourcemaps и symlinks запрещены. Проверяются известные сигнатуры credentials; это не универсальный детектор любых секретов.

При необходимости получения статического архива после clean commit, build и тестов:

```bash
npm run package:preview -- /absolute/artifact-directory
```

Проверяются source commit, clean tree и digest dist. Архив содержит только статические файлы; SHA-256, file list и source metadata создаются рядом, вне архива. На VPS Node/backend/миграции не нужны.

[Будущее размещение](deploy/preview-release.md) предусматривает отдельные releases/current, Basic Auth, действующий HTTP ACME challenge и откат на holding page. Эта инструкция не применялась; ни Nginx, ни app.wish-bot.ru, wish-bot.ru, webhook или smalltalk.wish-bot.ru не изменялись. Остановка перед размещением для визуального согласования.
