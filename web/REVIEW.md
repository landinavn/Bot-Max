# Frontend 1.3 — визуальное согласование

Продолжение `feature/web-frontend`, PR №257, база `fe15576e5793b4d759721ff77e640bc5ae3229f4`. Дата итоговой проверки — 27 ноября 2026. Все изменения ограничены `web/`; backend, тарифы, авторизация, оплата, БД и MAX не затронуты. Deployment и merge не выполнялись.

## Результат

1. Hero с оригинальным логотипом, официальным названием, согласованным заголовком/подзаголовком и двумя CTA. Семейная и индивидуальная фотосессии, детская открытка, карта желаний, кадр Деда Мороза. Основная кнопка видна на первом экране всех проверенных размеров.
2. Новогодняя коллекция из четырёх направлений без таймеров, выдуманных акций и цен.
3. Каталог девяти услуг; оживление представлено настоящим кадром предоставленного ролика.
4. Фотогалерея: семь различных работ, четыре подтверждённые категории. Для пары фотосессия не заявлена. Desktop — разная композиция; mobile — горизонтальный rail, фильтры, кнопки Назад/Далее и увеличение.
5. Отдельный блок открыток: пять рекламных композиций целиком + готовая открытка для внучки. Новые пары не конструируются.
6. Дед Мороз: реальный пример, имя и личные факты, фото и один/несколько детей; сохранены правила продукта.
7. Карта желаний: финансовая мечта и дом у моря, без гарантий исполнения. Прежняя подтверждённая интерактивная пара сохранена.
8. **После карты желаний** — «Оживите самые дорогие воспоминания» с двумя видео 5.04s, явными кнопками и CTA. Исходные пропорции 784×1176 и 1072×856 сохранены. Постеры — кадры 1s, не оригинальные фото; before/after не придуман.
9. Мультфильмы, песни и музыкальные открытки: реальные видео/аудио по нажатию, без ранней загрузки и autoplay. Минутный фрагмент песни не выдаётся за полную песню.
10. Далее: как это работает, условия стоимости, FAQ и финальный CTA.

## Медиа и разрешения

Три ZIP распакованы в одну приватную директорию. Все 14 изображений + 2 видео совпали с SHA-256 из `sources.tsv`. Получено отдельное подтверждение владельца: «Да, разрешаю все 16 файлов», включая узнаваемых взрослых и детей (26 ноября 2026).

Обработаны только предоставленные оригиналы: без AI-перерисовки, новых людей, ретуши, обрезки рекламных текстов и фиктивных сравнений. Нативные пропорции сохранены через contain/нативные размеры. Новые рекламные композиции заменяют два старых Telegram-баннера; оригиналы не переписывались. Старые family-2/3 убраны как визуальные дубли новых исходников.

[Приватный реестр и описание](media/README.md), [manifest](media/manifest.json), [исходный TSV](media/frontend-1.3-sources.tsv) остаются вне public/dist. Public — только 65 зарегистрированных файлов. У всех есть hashes/bytes/source/approval; responsiveMedia содержит только публичные paths/dimensions.

## Размер и начальная загрузка

Размеры относятся к локальному static preview, без HTTP gzip/Brotli. Фактический объём после server-side сжатия может отличаться. Fresh browser context, без cache, до прокрутки и любого воспроизведения; native lazy loading может заранее взять ближайшие изображения ниже fold. Нет утверждения, что загружаются исключительно видимые пиксели.

Показатели финальной сборки и initial network фиксируются в `frontend-1.3-summary.json` рядом со скриншотами; источник измерений — `browser-report.json`. Полный dist содержит 89 статических файлов; реестр, README, TSV, исходники, `.env`, Git, Python и БД в него не входят.

## Граница готовности

Подготовлен preview для визуального согласования. `readyForIndexing=false`, noindex/robots и прежние 19 маршрутов сохранены. Недействующие кабинет/веб-оплата/генерации не имитируются. Индивидуальный заказ остаётся честным обсуждением идеи, без выдуманного примера. Юридические документы/контакты, Basic Auth и размещение на сервере остаются отдельными задачами.

Не применялись Nginx-конфигурации, миграции, backend-процессы, production загрузки или merge PR. Бот, рабочая БД, реальные пользователи и платные операции не изменены. После commit/PR остановиться для согласования.
